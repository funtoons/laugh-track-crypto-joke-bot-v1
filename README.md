One line, under 200 characters, about crypto and trading life — for the
[Laugh Track: The Crypto Trading Joke Contest](https://make.fun/bounty/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a) on make.fun.

## The joke

> I used 100x leverage because I was 99% sure. The market took the 1%.

## How it works

`main.py` (Python standard library only, deterministic, offline) writes that
single line to `/output/entry.txt`. No randomness, no network, no timestamps.

Run it:

```sh
python3 main.py
```
